# AWS Three-Tier Architecture Project

## Project Overview

This project demonstrates the implementation of a three-tier architecture using AWS cloud services.

The architecture separates the application into different layers to provide a structured and scalable cloud environment.

## Architecture

The project consists of three main layers:

1. Presentation Layer
2. Application Layer
3. Database Layer

## AWS Services Used

- Amazon VPC
- Amazon EC2
- Application Load Balancer
- Amazon RDS
- Internet Gateway
- Subnets
- Route Tables
- Security Groups

## Architecture Flow

Users
↓
Application Load Balancer
↓
Application Layer
↓
Database Layer
↓
Amazon RDS

## What I Did

- Created an Amazon VPC
- Configured public and private subnets
- Configured Internet Gateway
- Configured route tables
- Configured security groups
- Deployed EC2 instances
- Configured Application Load Balancer
- Configured database layer using Amazon RDS
- Tested connectivity between the different layers
